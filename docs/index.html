产品介绍

让商品图收集不再手忙脚乱

电商详情页图片散落在主图、SKU、详情长图中，右键保存费时且格式不一。图提取帮你一次扫清、统一导出。

图片太分散

主图轮播、规格图、详情图分布在不同模块，手动翻找容易遗漏。

无法批量保存

浏览器默认只能单张另存，运营与设计需要整套素材时效率极低。

格式不统一

原图多为 JPG / WebP，后续编辑不便。插件统一转为 PNG，方便二次使用。

核心功能

从提取到下载，一步到位

面向真实电商页面做过兼容：懒加载、背景图、相对路径都能处理。

一键提取

自动扫描页面所有商品图，兼容 data-src、srcset 等懒加载写法。

智能过滤

自动排除图标、logo、占位图与过小尺寸图片，留下真正的商品图。

集中预览

在新标签页以网格展示全部结果，缩略图与尺寸信息一目了然。

自由勾选

支持全选、反选与单张勾选，只下载你真正需要的那几张。

统一 PNG

无论原图是 JPG 还是 WebP，均自动转换为 PNG，便于编辑与归档。

批量下载

一键保存到浏览器默认下载目录，文件名按「商品图_001」自动编号。

安装步骤

四步加载到 Chrome

Manifest V3 扩展，通过开发者模式加载已解压文件夹即可使用。

  1. 1

    下载并解压

    下载插件压缩包，解压到本地任意文件夹（例如 D:\image-plugin）。

  2. 2

    打开扩展管理页

    打开 Chrome，在地址栏输入 chrome://extensions 后回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择刚才解压出的文件夹。完成后打开商品详情页即可看到「获取图片」按钮。
